## What's New in v2.1

### Tier 1 — Core Intelligence (was stubbed in v2.0)
1. **Real AI (Claude API)** — Questionnaire auto-fill with confidence scores, evidence citations, prompt injection protection, 200-question cap, token tracking
2. **Evidence Parsing (Azure Document Intelligence)** — SOC 2, ISO 27001, pen test extractors with real document analysis, MinIO storage
3. **Evidence-to-Control Mapping** — Keyword-based mapping engine, internal service APIs, confidence scoring
4. **SSO/SAML/OIDC** — OIDC flow, JIT user provisioning, User model extended
5. **Vendor Portal** — White-labeled portal with auth, dashboard, assessments, evidence, findings pages
6. **External Ratings (SecurityScorecard)** — API client, score normalization (0-100)

### Tier 2 — Automation
7. **Assessment Distribution** — Distribute with email + SLA timers + due dates
8. **Real Email (SendGrid)** — Template rendering (sandboxed Jinja2), assessment invitations, reminders
9. **Alert Correlation** — P0-P4 auto-priority, 24h deduplication, 48h correlation escalation
10. **Temporal Workflows** — Pre-wired activities for all services

### Tier 3 — Intelligence
11. **FAIR Quantification** — Monte Carlo simulation (10K iterations), ALE with percentile ranges
12. **Board-Ready Reports** — PDF (WeasyPrint), PPTX (python-pptx), branded templates, AI narratives
